# com.finbourne.sdk.services.lusid.model.OverrideVirtualTransactionsRequest
classname OverrideVirtualTransactionsRequest
Upserts overrides, suppressions and adjustments of virtual transactions generated by a single instrument event.  Overrides and adjustments are keyed by the virtual transaction id they target; suppressions are the list of  virtual transaction ids being suppressed. A virtual transaction id must appear in only one of them. This is a  full replace of the previously stored overrides, suppressions and adjustments for the targeted instrument  event - any previously stored entry not present in this request is removed.
